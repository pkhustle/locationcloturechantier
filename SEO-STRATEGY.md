# SEO Strategy — Location Clôture Chantier (Québec)

**Goal:** Rank organic top 3 across Québec for "location clôture chantier" + long-tail matrix.
**Model:** Lead-gen / referral (no physical location → organic-only, no Maps 3-pack).
**Status:** Brand-new domain. Realistic head-term top 3 = 6–12 months; long-tail wins in 2–4 months.

---

## 1. The strategic position (our wedge)

The Québec SERP is dominated by **real rental operators with thin, transactional service pages**
(Groupe Choquette, Clôture Sécure, cloturetemporaire.com, Location GM, Échafauds Plus, Falardeau,
Modu-Loc). Evidence the niche rewards *content*: the page ranking for the commercial query
"frais de location de clôture de chantier" is a **Modu-Loc blog post**, not a product page.

**Our position:** the neutral, Québec-wide *resource + provider directory* — genuinely more useful
than any single operator's site. Three defensible content moats no competitor owns:

1. **Municipal permit database** — every Québec city has different clôture rules (height minimums,
   permit-on-public-domain). Aggregating this = unique, useful, un-spammable content per city page.
2. **CNESST compliance guide** — mandatory *avis d'ouverture* (10 days before), site-security norms.
3. **Price transparency + calculator** — built on real data ($0.30–$0.80/linear ft/mo; ~$15/day/8ft
   panel; delivery + install + fuel surcharge + removal).

This is what keeps a lead-gen site out of Google's thin-content / doorway-page penalty zone.

---

## 2. Domain

- **Recommended:** `locationcloturechantier.ca` (near-EMD, `.ca` = Québec/Canada trust signal).
  Partial-match `locationcloture.ca` is already taken, confirming demand.
- Build a light **brand** on top (logo, name, author identity) so it doesn't read as a pure doorway.
- Alternatives if EMD feels spammy: a brandable + descriptive combo (e.g. `ChantierClôture.ca`).

**Internal linking:** every city page → relevant type pages + guides + /soumission. Guides →
cities. Directory → cities. Head-term home links to the 5 highest-demand cities + top guides.

## 4. Quality gates (avoid index bloat / thin content)

| Rule | Value |
|---|---|
| City pages — tier 1 launch | Top **5** (Montréal, Québec, Laval, Gatineau, Longueuil) |
| City pages — full rollout cap | **~30–40** real-demand municipalities, NOT all 1,100 |
| City×type combos | Only for tier-1 cities (5 cities × 6 types = 30 max) |
| Min unique content / city page | 600 words, 60%+ unique (local permit rule + demand + providers) |
| Type page | 800 words, 100% unique |
| Index rule | Combos with no unique data → `noindex` or don't build |

**What makes each city page unique (mandatory):** that city's actual clôture bylaw + permit link,
local providers serving it, typical coverage radius, local pricing notes, borough/MRC context.
No spun boilerplate — if a city has nothing unique to say, don't publish it.

## 6. Content & E-E-A-T plan

- **Editorial identity:** named author/editor with construction/rental credentials, real /a-propos,
  contact, editorial policy. Critical for a lead-gen site to earn trust.
- **Pillar content (build first):** prix guide, permis database, CNESST guide, comment-choisir.
- **Schema:** `Service` + `FAQPage` on type/city pages, `HowTo` on guides, `Organization` +
  `WebSite` sitewide, `AggregateRating` only if real reviews. (No `LocalBusiness` — no physical loc.)
- **GEO / AI search:** quotable price ranges, structured FAQ, clear definitions → wins AI Overviews &
  ChatGPT/Perplexity citations for "combien coûte…" / "faut-il un permis…" queries.

---

## 7. Implementation roadmap

**Phase 1 — Foundation (wk 1–4):** domain + static stack (Astro/Next static for Core Web Vitals),
home + a-propos + contact + soumission, top-5 city pages, prix guide, base schema, GSC/GA4.

**Phase 2 — Expansion (wk 5–12):** 6 type pages, permit-database hub + 15 more city pages, CNESST
guide, calculator, provider directory + onboarding of first referral partners, internal linking.

**Phase 3 — Scale (wk 13–24):** city×type combos (tier-1), remaining cities to ~35, link building
(construction associations, municipal resource pages, supplier partnerships), GEO optimization.

**Phase 4 — Authority (mo 7–12):** deepen guides, digital PR / citations, push head term to top 3,
continuous CWV + content refresh.

## 9. Primary risks

1. **Thin-content demotion** → mitigated by permit DB + real per-city data + editorial identity.
2. **Lead-gen trust deficit** → real author, transparent "how we make money", genuine directory.
3. **Enough providers to route leads** → onboard referral partners in Phase 2 before scaling traffic.
4. **New-domain patience** → win long-tail first, compound authority toward head term.
